<h2 align="center">👨‍💻 Sobre mim</h2>

Sou <strong>Backend Software Engineer</strong> com foco em <strong>Java e Spring Boot</strong>, atuando principalmente com desenvolvimento de APIs, integrações, segurança, bancos de dados e aplicações backend em produção.

Gosto de trabalhar com desafios relacionados a <strong>arquitetura backend, performance, observabilidade, segurança, automação, cloud e integração entre sistemas</strong>.

No dia a dia tenho contato com tecnologias como <strong>Java, Spring Boot, PostgreSQL, Redis, RabbitMQ, Docker, Kubernetes, AWS, Terraform e GitHub Actions</strong>.

Atualmente também venho aprofundando meus conhecimentos em <strong>Golang e Quarkus</strong>, explorando diferentes abordagens para construção de serviços performáticos, microsserviços e aplicações cloud-native.

Além disso, utilizo <strong>IA aplicada à Engenharia de Software</strong>, com ferramentas como Claude Code, OpenAI Codex e agentes baseados em LLM para análise de codebase, debugging, refatoração, testes, code review, hardening e automação de workflows.
